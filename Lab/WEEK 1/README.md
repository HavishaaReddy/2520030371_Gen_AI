WEEK 1 : LLM API CALL

This experiment is a simple Python program that connects to Google Gemini using an API key and generates a response for a user prompt.

Files:
main.py – sends the prompt and prints the response
.env – stores the Gemini API key
requirements.txt – required Python packages
.gitignore – ignores unnecessary files

Setup:

1. Install the required packages: pip install -r requirements.txt
2. Add your Gemini API key to the .env file:
   GEMINI_API_KEY=your_api_key
3. Sample Prompt: What is Artificial Intelligence? Explain in simple words.

Run: python main.py

Output: The program returns a response generated by Gemini and displays it in the terminal.
