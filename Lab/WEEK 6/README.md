WEEK 6 - Llama 3.2 Baseline Run

This experiment is used to test the answers generated by the Llama 3.2 model using a predefined set of Generative AI questions. The generated answers are checked using keywords and the results are stored in a CSV file.

Files:
1. main.py: Main program file.
2. golden_set.json: Contains questions, expected answers, keywords and sources.
3. requirements.txt: Contains required Python package information.
4. baseline_results.csv: Output file generated after execution.

Setup:
1. Install Python.
2. Install Ollama.
3. Download the model: ollama pull llama3.2

Install required package: pip install requests

Run: python main.py

Output: The program reads all questions from the JSON file and sends them to Llama 3.2.
For every question, the following details are displayed:

- Generated answer
- Expected answer
- Matched keywords
- Missing keywords
- Score
- Status
  
After completion, a summary is displayed and the results are saved in: baseline_results.csv

Result: The experiment performs a basic evaluation of Llama 3.2 using a golden question set and keyword matching approach.
